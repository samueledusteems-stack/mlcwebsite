# mangoSTEEMS website concept

This is a static HTML, CSS and JavaScript site concept prepared for Vercel.

## Deploy with Vercel

1. Put this folder in a GitHub repository, or import the repository that contains it in Vercel.
2. In Vercel, set the **Root Directory** to this folder if it is inside a larger repository.
3. Use the **Other** framework preset. The included `vercel.json` also sets this project to static output with no build command.
4. Deploy. `index.html` is the site entry point.

There are no package dependencies or build step. The logo, photography and web fonts currently load from the live mangoSTEEMS site and Google Fonts, so those references need to remain publicly available for the page to look as intended.

## Before publishing

- Replace the student project, parent feedback and event placeholders with approved real content.
- Confirm the centre list, programme information, enquiry destination and contact details.
- Confirm that the live-site images and logo are approved for reuse on this deployment.
